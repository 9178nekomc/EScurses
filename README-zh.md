# Escurses
一个可以让你做出终端游戏的python库

## 为什么你有必要选择Escurses?
  - 跨平台支持
    它可以在Windows上用，也可以在Linux上用
    所以你不用因为这个库不兼容系统而担心，除非你在用macOS
  - 易用
    你只需要下载它然后把它丢进你的代码目录里，然后你就可以用了！

## 文档
首先，如果你是linux党，那我得教你个函数
  - `linuxTerminalCheck()`
      这个函数用于检测你是不是在tty环境内，无论你要搞阻塞输入还是无阻塞输入，你都有必要用这个函数检测一下环境
      当它返回`True`时，这代表你确实在tty环境里，但如果它返回`False`，那说明你可能不在纯tty环境内，这可能会导致阻塞错乱
  
然后就是接下来的事了
  - `getTerminalSize()`
    这个函数会返回一个元组，它的第一个元素是屏幕的长度（以字符数计算），第二关元素是屏幕的宽度
  - `initGame()`
    它负责初始化`_maxScreenWidth`和`_maxScreenHeight`，当然，我不建议你直接用这两个变量来做你的游戏，这属于是内部变量了
  - `clear()`
    很简单，就是清屏
  - `getch(nodelay=True)`
    最难实现的一个，因为它同时包含了Windows的输入，Linux的输入，且两个系统的输入都有分别的阻塞版和无阻塞版，通过`nodelay`这个参数来控制，默认是`True`
    如果你开了无阻塞输入，那么当你没有按任何按键时，他会返回`None`
  - `drawChar(x, y, char)`
    它会在指定的`x`和`y`画一个你传入的字符，然后就没了，就这么简单
    至于它的原理......好吧我可以讲讲
    其实我们还有一个内部变量`_screen`，这是一个数组，里面存的是各个位置对应的字符，当你调用这个函数时，它会把你传入的字符和你传入的坐标组合成一个元组丢进这个数组的对应位置里，但是左上角的坐标其实是(1,1)而不是(0,0)
  - `refresh()`
    调用这个函数会将`_screen`数组里的字符一一遍历出来画到屏幕上
  - `cursorEcho(echo=False)`
    当你往`echo`里传入`False`，这会隐藏你的光标
    如果传入`True`，光标又会显示出来
    以及`echo`的默认值为`False`
  - `exitGame()`
    用于退出游戏

这基本就是全部内容了，祝你们能做出好的游戏！（虽然这个库基本没啥用）
